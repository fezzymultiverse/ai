YouTube music source

Default sources

Horizon searches and fetches audio through Piped or Invidious servers, the same idea as NewPipe, with no Google login. Put one server per line. Start a line with inv: for Invidious. Leave empty for the defaults. Public servers come and go, so use Test and swap in one that works.

Use the red YouTube button beside + to switch YouTube on for a chat, then ask Horizon for music.
