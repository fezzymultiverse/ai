Horizon V1.92.0 - WhatsApp silent send + relay
- Silent background send toggle (default OFF): no dialog, WhatsApp never opens. 10 sends/hour cap.
- Reply actions survive notification dismissal; stale ones fail cleanly and report "Nothing was sent".
- No live reply action: Horizon posts a tap-to-send notification and the AI is told to inform you.
- "AI sees new messages and reads without asking" toggle: recent previews go into the AI context.
- Needs: Notification access, Allow confirmed replies ON, contact must have messaged since Horizon connected.
- Not integrated: WhatsApp Business Cloud API (needs Meta token + phone number ID + a webhook server).
- Not device-verified: Kotlin was not compiled here; build via CI.

Also in V1.92.0
- Colors: every light/neon green (chips, tool-menu active rows, step LEDs, terminal text) now uses --neon (#bf5fff) on dark pills; light themes use --neon-deep. PDF export colors untouched.
- Stale code: 268 overridden duplicate CSS declarations removed; old reports, __pycache__ and screenshots removed. All 59 scripts are loaded and none are orphaned.
- Cache: asset version bumped to 1.92.0 so the one-time cache/service-worker cleanup runs again on first launch.
- Speed: chat save debounced (400 ms, flushed on hide/backup); Lite mode (auto on <=4 GB RAM or <=6 cores) removes shadows/blur; chips poll slower. Set localStorage hzLite=0 to turn Lite off.
- Terminal: the AI is now told when Termux is installed but off and how to switch it on. Defaults are still OFF; set AI mode to AUTO for background runs.
- Not device-measured: no phone profile was possible here; Kotlin not compiled.
