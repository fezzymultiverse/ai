HORIZON V1.88.0 — CONSOLIDATED TERMINAL / PERMISSIONS RELEASE
Source upgrade from the uploaded Horizon V1.87.1 archive

DELIVERY
This is updated SOURCE, not an APK and not an installation on your phone.
Use the existing GitHub Build Android APK workflow to produce the new APK. Update
with the same application ID and signing key to preserve the existing installation.
Do not clear application data to fix a layout: that could erase your local keys/chats.
The version is now 1.88.0. About & Updates displays this version.

WHAT CHANGED
1. Five right-panel app tiles are side by side in ONE row: Music, Terminal, Lens,
   YouTube, Contacts. Checked at 320, 412 and 768 CSS pixels.
2. Settings > Permissions is back as a real settings page. Device/native check,
   existing device access controls and WhatsApp Personal/Business live there.
   The Device check was moved from Vault rather than cloned. The existing WhatsApp
   source switches, inbox, contacts, confirmed replies and privacy gates remain.
3. One large TERMINAL owns Termux commands. The small Termux command textarea,
   duplicate output view and Horizon's separate Android-native shell were removed.
   Its native plugin registration, source and obsolete AI shell.exec path were removed.
   A single bridge routes manual commands, AI commands and Termux download helpers.
   Approval is still mandatory. Concurrent submissions within the active WebView
   are refused; unknown completion is not treated as cancelled.
4. TERMINAL > Controls / Options contains bridge enablement, Run commands permission,
   Termux setup, optional AI gate, Test bridge, Install download tools and Recent jobs.
   Setup actions write their results into the large terminal, not a second shell box.
5. AI instructions now explain supported music/audio/video/file downloads, yt-dlp,
   FFmpeg, aria2c and curl, installation requirements, safe destination paths and
   truthful completion reporting. Existing YouTube, music and file-download routes
   remain in place. Commands do not bypass root, DRM, authentication or Android.
6. One paste/review box at the BOTTOM of Web Scraping handles both AI and scraper
   API keys. The API Providers importer now links to that same box; no second note
   editor, secret parser or credential store was added. It supports labelled notes,
   JSON, environment variables, markdown, common copied HTML and zero-width debris.
   Matches are deduplicated and masked; ambiguous opaque keys require service labels.
   Extract never saves or sends anything. Verify & save sends each selected key only
   to its matching provider. Existing AI keys stay intact; verified extras are backups.
   Existing scraper keys require replacement confirmation. Failed/mixed notes remain
   available for correction. Full raw notes are never sent to the AI or logged.
7. Fixed Firecrawl validation treating certain HTTP errors as a successful save.
8. Three lightweight chat visuals: role-colour rails + metadata badges; a static
   dot-grid canvas; improved code/table reading surfaces. No image generation,
   animated canvas, duplicate message renderer or new chat polling loop.
9. The old stylesheet patch pile is replaced by ONE canonical www/horizon_app.css.
   Its existing cascade order is preserved; old individual CSS files were removed.
   Conflicting old three-column app dock rules were removed rather than hidden.
   JS/CSS assets are release-versioned. An upgrade clears resource cache only, plus
   known obsolete layout/shell preferences; chats, Vault, keys and databases are kept.
   Legacy Horizon service-worker/cache cleanup is bounded to identified app resources.
10. Terminal output is inserted in batches, history is bounded, terminal AI attaches
    through a dedicated event instead of a body observer, Termux options build lazily,
    laser decoration no longer wakes an idle 300ms timer, and decorative work respects
    background/editor/reduced-motion states. Background music/downloads are not disabled.

IMPORTANT TERMUX LIMITS
Initialize the standard Termux app once, enable allow-external-apps=true in
~/.termux/termux.properties, enable Horizon's bridge and grant Run commands.
Use Install download tools to install Python, FFmpeg, aria2, curl and yt-dlp.
Shared Downloads access additionally needs Termux storage access; otherwise files go
under $HOME/horizon-downloads. Run termux-setup-storage in Termux itself if needed.
This bridge runs real bash commands, but it is not an interactive PTY: no interactive
stdin, SSH editor, password prompt or persistent aliases/environment. cd is retained
as a path between manual commands. Ctrl+C cannot cancel a submitted background job;
stop it in Termux. Timeouts can mean it is still running. Inspect Recent jobs/results
and Termux before retrying, especially after process death or an interrupted setup.
No responsible source-only audit can guarantee zero bugs across all Android devices.
