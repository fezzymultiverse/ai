HORIZON V1.89.0 — PROVIDER ENDPOINT FIX
Source patch on the uploaded Horizon V1.88.0 archive

PROBLEM
AnyAPI, Routeway and GonkaRouter all showed "Unsupported AI endpoint". The Android
bridge (HorizonAIPlugin.kt, request()) only allowed six AI hosts and rejected these
three before any network request was made. Keys and models were never the cause.

CHANGES
1. Allowlist now includes api.anyapi.ai, api.routeway.ai, api.gonkarouter.io.
2. Notification text parser reads GonkaRouter's content-array reply.
3. New tests/endpoint-allowlist.test.cjs guards against this class of bug.
4. Version bumped to 1.89.0 (package.json, package-lock.json, index.html asset
   versions, horizon_release.js, horizon_about.js, horizon_app.css, docs, README).

STATUS
