# V1.99.100 - Layout migration: Widgets left, Menu right, one media unit

Changed: www/index.html, NEW www/horizon_layout.css, NEW www/horizon_unit.js, www/horizon_rpidle.js.

1. LEFT panel is now "Widgets" only, in this order: clock/weather/device card, the MEDIA UNIT, the apps dock (six across).
2. RIGHT panel is now "Menu". New rows on top, each opening as its own page (no drop-downs): CHATS, PROMPT & MEMORIES (the old Prompt & Preferences and AI Memories merged into one page), ARCHIVE. Then the existing settings rows, unchanged.
3. Same element ids everywhere (chatList, personaInput, memList, hzArchive, hzDash, hzRadio, hzRpMedia, mpMini, hzDock...), so every module that mounts by id keeps working. The panels were only re-parented.
4. Old callers openPanel('left','chats'|'prompt'|'memories'|'archive') are redirected to the matching right-panel page.
5. MEDIA UNIT (horizon_unit.js): one flat-screen frame with a MUSIC / RADIO switch. Music face = player, waveform, lyrics, idle screensaver. Radio face = Horizon Radio. The unit flips to whichever the AI starts, shows the AI's last [[music.*]] / [[radio.*]] command and its result on the AI LINK line, and exposes window.HorizonMedia { face, now, radio, music }. The music and radio engines are untouched.
6. The right-panel media and dock CSS rules were repeated for #leftPanel (horizon_layout.css part 1).
7. NOT DONE YET: radio does not yet feed the shared waveform canvas or the lyrics box; it keeps its own dial. Next step if you want radio literally on the player's screen.
8. Not tested on a phone. Loaded in headless Chromium: no page errors, both panels open, Prompt & Memories page opens.
