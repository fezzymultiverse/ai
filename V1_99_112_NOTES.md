# V1.99.112 - key check fixed, Claude / ChatGPT / DeepSeek / Groq / xAI removed

FIXED: "That key belongs to openai, not typhoon / agnes / gonka" (Typhoon, Agnes AI, GonkaRouter, and Zro, Ollama, Gonka Broker too).
Cause: www/horizon_key_import.js treated any bare sk- key (sk- plus 40+ letters/digits, or sk- plus 32 hex) as an OpenAI/DeepSeek key. Typhoon, Agnes, GonkaRouter and others issue that same shape, so Save & validate refused them before any request went out. A bare sk- key proves nothing about who owns it; it is now accepted for any provider. Keys with a real unique prefix (thk_live_, AIza...) still refuse the wrong provider.
