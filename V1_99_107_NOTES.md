# V1.99.107 - Cloudflare backup key: Account ID box (includes V1.99.106 one-screen media unit)

EDITED: www/index.html only (this change). Version strings still 1.99.103, as in V1.99.105 and V1.99.106.

Problem: the main Cloudflare card has Account ID + API token boxes, but the Backup keys slot had one box, so there was nowhere to put the Account ID for a backup.

Fix (implemented):
1. The Cloudflare card's Backup keys area now has "Backup Account ID" and "Backup API token" boxes. Add (or pasting the token) joins them as ACCOUNT_ID:API_TOKEN and saves them as ONE backup slot, same list as before (horizon_xkeys_cloudflare), so rotation, Test all keys and the Vault list see it as a normal backup.
2. Pasting a ready-made ACCOUNT_ID:API_TOKEN into the token box still works with the Account ID box empty.
3. Token with no Account ID, or an Account ID that is not 32 letters/numbers: nothing is saved, the Account ID box turns red and a message says what is missing.
4. After a successful save both boxes empty, ready for the next backup (a backup is usually another account, since the free allowance is per account).
Other providers' backup boxes are unchanged.

Tested: headless Chromium, box and labels present, empty/short Account ID refused with nothing saved, good-format Account ID passes the format check, no page errors. NOT tested: the live verification call against Cloudflare (no network here), so a real key saving as VERIFIED is still to be confirmed on the phone.
