1. KEY SAVE: "no free model produced text" no longer throws away a good key. 2. TEST ALL KEYS: one cheap request per key (OpenRouter: /auth/key, no quota used; others: one probe of the selected model) instead of the whole audit. That was the 33s ERROR.
3. AGNES / OLLAMA / GONKA: a failed model LIST (Agnes HTTP 401) no longer aborts. The documented models are probed with a real chat call; if that also returns 401 you get "key rejected" instead of a catalogue error.
4. MLVOCA: POST limit 18s -> 110s (GET 15s), because the shared server and deepseek-r1:1.5b need longer. Audit gap 13s to respect its 5 requests a minute.
5. FREE.AI: "Model substitution refused: qwen3-8b -> Qwen3-30B-A3B-Instruct" fixed. Same model family is accepted for free.ai only (alias also recorded in the inventory); a different family is still refused. POST limit 60s.
