# V1.99.119 - Choose folder for AI file access (no more typing paths)

Built on V1.99.118. This one touches native Java, so rebuild the APK (not only a web sync).

WHAT CHANGED
- Permissions panel > File access card: new "Choose folder" button. It opens Android's own folder picker. Tap it again to add more folders (up to 24). Each chosen folder is listed with a Remove button.
- A chosen folder counts as "named". You no longer have to type or remember a path in chat. Just say what you want ("sort my Pictures by place") and the AI works inside the folders you picked.
- The AI is told the exact chosen paths, can declare scope with [[files.scope: all]] or by plain folder name, and still shows the Apply / Cancel plan card before anything moves.
- Typing a full path in chat still works exactly as before.

SAFETY (unchanged unless noted)
- Android/data and Android/obb stay blocked, even if picked.
- The whole storage root cannot be picked, only a folder inside it.
- Picking a folder named Vault or Termux counts as naming it on purpose. Sub-folders called vault/termux inside a chosen folder stay protected unless you name them.
- "leave X alone", Retreat, Undo, same-volume no-overwrite rename, Documents/Trash: all as before.
- Removing a folder drops the AI's scope straight away; it must re-declare on the next message.

FILES
- android-native/app/HorizonFilesAccessPlugin.java: folders / pickFolder / removeFolder, declareScope accepts chosen folders (empty scope = all chosen).
- android-native/app/HorizonFilesState.java: chosen-folder store, allowedRoot, protect() treats a picked folder as explicitly named.
- www/horizon_files.js + horizon_files.css: Choose folder UI, AI prompt block, scope mapping.
- No manifest change (ACTION_OPEN_DOCUMENT_TREE needs no permission).

NOT tested on a phone.
