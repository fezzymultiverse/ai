# V1.99.116 - BAD key indicator and Vault export

Built on horizon-V1_99_115.zip. No native (Kotlin) change, so no APK rebuild is needed for this; a normal web assets sync is enough.

BAD KEY INDICATOR (indicator only, nothing is deleted for you)
- New www/horizon_keyhealth.js remembers which keys the app has seen rejected. A key is flagged BAD on HTTP 401/403 or an "invalid key" message. It stays BAD until that same key works again. Rate limits / out of credit show as LIMITED and fade after 6 hours.
- Keys are never stored in it: only a one-way fingerprint, the last 4 characters, provider, HTTP code, message and time.
- Where you see it:
  - Provider card: red "BAD KEY" banner (Main/Backup, last 4, HTTP code, how long ago) and a red card border.
  - Backup slot rows: BAD / LIMITED straight from real use, before you tap Test all keys. Test all keys feeds the same flag (only a real REJECTED flags; network errors flag nothing).
  - Scraping keys list: BAD / LIMITED tag next to the key.
  - Vault: BAD KEY badge and red edge on the item, a "Bad N" filter chip, "N BAD" in the status line, BAD on "Keys in Horizon" rows, and a line "Rejected by Groq (HTTP 401) 5 min ago. Delete this item when you are ready."
  - Settings: a red dot on the HORIZON VAULT row while any key is BAD.
  - A toast the moment a key turns BAD.
- Rotation: scraping keys already rotate (main, then backups). A BAD key now goes to the back of the line so rotation lands on a working key first, it is still tried last, and the toast says it is rotating. AI chat is still manual (no auto rotation), so a BAD AI key just gets the indicator.
- Saving or re-validating a key that passes the provider check clears its old BAD flag.

VAULT EXPORT
- New "Export" button next to Detect keys.
- What: Everything / Notes only / Keys only. Format: JSON (full backup with dates and key health), Readable text, or .env lines (keys only; SSH keys are left out because they are multi-line). Option to include the keys from the provider cards (main + backups).
- Plain text on purpose. The panel warns and the Save button needs a second tap. Copy button copies the same content.
- Saves through the same path as the other exports (Downloads via HorizonAI.saveText, then Documents/Horizon, then a browser download). File name: horizon-vault-everything-YYYYMMDD-HHMM.json / .txt / .env.txt.
- Locking the Vault hides and clears the panel.
