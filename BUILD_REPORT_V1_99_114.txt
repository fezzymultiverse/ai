6. KNOWN LIMITS / LEFT UNDONE
  UNTESTED — full Gradle/NDK APK build and all device acceptance checks. No Android SDK/device or release signing key was used here. The existing CI still requires its normal repository signing secrets; none have been invented or embedded.
  Build now needs CMake 3.22.1 and the Android NDK for the tiny atomic-rename library; CI installs CMake and Gradle handles the NDK. Native/kernel lack of renameat2 fails closed, never copies or overwrites.
  Folder viewer currently supports primary shared storage document URIs. Secondary/removable volume folder viewing returns a clear OUT_OF_SCOPE result; same-volume native administration can operate in named accessible roots. OEM/file-manager URI support is UNTESTED.
  Exclusions are native mechanical matching for explicit English directives such as leave Screenshots alone, except Folder, skip Folder, do not touch Folder and keep Folder unchanged. Recognized ambiguous negative language fails closed. Arbitrary natural-language interpretation, other languages and unusual phrasing are not guaranteed: use explicit folder names/paths.
  Undo cannot silently reuse/expand old scope. After a new user message, chat switch or restart, name the original folder and declare scope again before Undo. A Retreat button does not erase the already-accepted scope for a deliberate Undo of completed work.
  Listings cap at 2000 inspected entries; transfers of directory trees exceeding the 2000-entry safety inspection cap are rejected. Directory transfers containing symlinks are rejected conservatively.
  A concurrent external filename collision after suffix selection returns a controlled error without overwriting; a fresh attempt selects the new suffix. External apps moving/changing filesystem paths during a run can still cause failures.
  EXIF support depends on format/header availability; unavailable dimensions may be zero and unsupported headers carry a metadata-status message. Geocoder may be unavailable or slow; unresolved GPS never exposes coordinates.
  Metadata cannot prove equal file content. The prompt explicitly prohibits claiming duplicates are content-identical on metadata alone.
  makeFolder is logged but not reversible: deleting folders would violate the no-delete requirement. Only completed move/rename/Trash rows offer Undo.
  The source prompt included conflicting Android/data wording. The implementation always blocks Android/data and Android/obb, even when named. This preserves Section 3.2 rather than the weaker sample prompt sentence.
  Historical release notes/comments/cache-key versions remain historical. Current package, release identity, About version constant, web diagnostics and inventory version are 1.99.114; no historical changelog was rewritten.
