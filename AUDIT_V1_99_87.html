Horizon V1.99.87 — verified free-tier picker, manual routing only

Audit date: 16 November 2026. Complete patched source, not an APK.

Scope and results

The actual supplied archive is horizon-V1_99_76-cfedge.zip (internal package version 1.99.75). The attached document describes a different later source, V1.99.85/86; that later archive was not supplied. This patch is based only on the actual uploaded source, not an assumed later revision.

186 provider/model probes; 87 non-empty text replies; 86 eligible provider/model picker choices across 15 providers. One BlockRun response returned text but named a different model and was excluded. These are choices, not 86 unique underlying models: aliases and the same model at different providers count separately.

This is bounded coverage of the supplied registry, publicly retrieved catalogues and the free-tier policies cited here—not a claim to find or verify every model worldwide. The raw audit includes unsuccessful non-chat catalogue candidates and aliases. Only the eligible, actually text-verified choices seed the working picker. A 429, 401, empty HTTP 200, timeout or inaccessible account is never counted as a working model.

The original source had 24 providers, not the 26 described in the reference document. All original provider cards remain. One additional keyless project, mlvoca, is added (25 total). It is a small public community API, not a production SLA, and permits non-commercial research/teaching/learning only. No speculative second or third anonymous provider is added merely to fill a quota.

What changed

Routing: automatic provider rescue, model walking, capacity-based model changes, backup-key rotation, the Groq vision-model substitution and OpenRouter free-router substitution are removed from the active chat path. A failed call remains failed, with the same provider/model selected. Retry is manual. Refreshing or importing keys does not replace an existing selection. Legacy Cloudflare migration code no longer replaces your saved selection.

OpenRouter fixed-model requests disallow upstream provider fallback and set zero input/output token price limits. Dynamic auto-router choices are excluded. Gonka’s preserved adapter includes its no-fallback header, but its signup-token trial is not treated as an ongoing free tier. Provider-reported model mismatches are refused; this is metadata validation, not independent proof of the underlying model weights. Pollinations’ audited openai/openai-fast aliases report gpt-oss-20b; a different reported target is refused.

Discovery: manual Save/Refresh reads the provider catalogue, follows supported same-origin pagination and tests every eligible model with a tiny synthetic prompt. It retains only actual text replies, uses no conversation history, and never changes the selected model. This can take several minutes under free-tier limits. No automatic catalogue replacement runs while answering a chat. Mlvoca has a documented fixed two-model catalogue because its /api/tags route is not public.

Cohere and Cloudflare: v2 Cohere uses a messages array; Cloudflare keeps separate Account ID/token input fields, puts Account ID in the URL and sends only the token as Bearer authorization. These structures already existed in the supplied source and were confirmed rather than falsely described as newly invented fixes.

Voice: all TTS menu boxes and Edge voice selector/test controls stack vertically with uniform box spacing. Every added CSS selector is scoped to #ttsCard. No other layout redesign was made. Voice-note transcription also uses only the selected Gemini/Groq provider, with no provider/key fallback. Android/Edge playback behavior outside the requested layout remains unchanged.

Important account and billing limits

Free-tier availability is not a universal no-charge guarantee for arbitrary keys. Use a free-tier Gemini/Groq project, a Cohere evaluation key, Cloudflare Workers Free, and an AionLabs free-only account without a prepaid balance. These providers can bill paid-tier accounts or paid balances for the very same model. Cohere evaluation and mlvoca have usage/license limitations. A successful text response alone does not prove a billed account was charged zero.

Mistral’s current official documentation explicitly says Free mode does not include API access. Its authenticated model catalogue was read, but no potentially billable Mistral chat was sent. Mistral, Gonka’s one-time trial and the original paid-only providers are disabled for chat in this free-only build. Original IDs remain in the complete inventory for traceability, not as enabled picker options.

OpenRouter: the supplied document contains exactly one OpenRouter key. All raw candidate requests returned HTTP 401, “User not found.” No additional OpenRouter keys were present to test. The fixed-model picker can repopulate after you supply a valid key and run Save/Refresh. Paid/free auto routers are intentionally excluded under the no-substitution requirement.

Cloudflare: authenticated catalogue access succeeded, so this was not simply a missing Account ID. Chat probes returned exhausted daily 10,000-neuron allocation, paid-plan-only model access or other errors. No Cloudflare text reply was verified; no Cloudflare model is pre-certified as working. Retest manually after the account’s free daily quota resets. Account-reported Free-plan-ineligible IDs are excluded in addition to the documented paid-plan-only list.

AnyAPI: most probes returned 429. Routeway recovered enough for five actual replies. Z.ai supplied two actual replies and one rate-limit result. AionLabs supplied six replies under its documented daily-credit free-tier basis, which is not intrinsic zero-token pricing. Public keyless services are quota-limited and untrusted: do not send private text. The phone-local G4F server cannot be reached from this remote environment; start it on your phone and explicitly refresh to certify models there. Its upstream service may have its own policies; Horizon cannot independently control an external local server’s internal routing.

Verification and security

221/221 unit tests passed, 13 browser integration scenarios passed, and all four inline application scripts passed syntax checks. Browser tests cover direct adapter routing, 429/403/402 failure, no backup key/model/provider calls, Cloudflare split credentials, Cohere messages, paid/router rejection, Groq image rejection, response-model mismatch rejection, selection preservation, transcription no-fallback, genuinely visible vertical TTS controls, and unchanged original chat/header/composer geometry at 360px and 412px. Every original stylesheet byte remains intact as a prefix; only voice-card-scoped rules were appended, and the original static body markup is unchanged.

No Android APK was compiled, installed or physically tested. Native files were inspected/patched and source/installer regression fixtures passed; real-device behavior and audio playback remain unverified. Existing historical browser suites were not all rerun; the new V87 routing/layout integration was run explicitly. Legacy unit expectations for automatic fallback and fixed old version strings were updated to the requested behavior, not skipped.

The secret-bearing DOCX and its redacted derivative were deleted from the sandbox immediately after the credential probes. No supplied keys were hardcoded into source or included in this ZIP. All original source files were scanned against the supplied secrets with zero matches. Only synthetic prompts and fake test credentials appear in tests. Your original uploaded files remain yours; this cleanup does not delete the uploads from your account. Revoke the temporary keys now.

How to use this source

Replace your repository files with the complete patched ZIP, then run your existing Android build workflow and install the resulting APK. Use your normal secret/key entry workflow; the package deliberately contains none of your credentials. Existing provider/model choices are preserved even if no longer available: select a verified option manually. Run Save/Refresh for a provider after adding a new key or after quota resets. The picker is a tested snapshot, not a promise of future availability.

Local checks: npm test; python3 scripts/check_inline_js.py. The V87 browser test requires Playwright/Chromium and the patched source served on port 8134 plus an unmodified baseline served on port 8135. It never calls real AI services; inference and external resources are mocked.
