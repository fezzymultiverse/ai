Horizon V1.93.0 - HD voice (Kokoro, open source) in Settings > Voice
Source patch on Horizon V1.92.4

CHANGES IN THIS RELEASE
1. New HD voice card at the top of Settings > Voice (open the Voice row). One tap downloads the Kokoro pack once (about 130 MB,
   official sherpa-onnx archive kokoro-int8-multi-lang-v1_0, Apache-2.0), selects it with the best voice (Heart) and Test plays it.
   It then runs offline through the same sherpa-onnx runtime as before: no key, no account, no limit. The Voice row subtitle says
   "open to get the free HD voice" until it is installed, and "HD voice (Heart ...)" once it is on. The Voice library rows below
   still work and share the same download (progress shows in both places).
   Buttons: Get HD voice / Cancel / Use HD voice (downloaded but another voice picked) / Test HD voice.
     www/index.html          #ttsHd card, paintHd(), wireHd(), copy in the Voice hint
     www/horizon_app.css     .tts-hd styles (end of file)
     www/horizon_tts.js      HorizonTTS.hd { pack, info, installed, active, use, get }
2. Kokoro voices listed best first (stars): Heart, Bella, Nicole, Fenrir, Michael, Puck, Emma, then the rest, weakest last. The order
   follows the quality grades in the Kokoro-82M voice list. When a pack is installed its voices now come before the 8 small built-in
   Kitten voices, so the default pick after a download is Heart. Speaker ids did not change (af 0-10, am 11-19, bf 20-23, bm 24-27);
   a test locks all 28.
3. Speed is made inside the model for every on-phone voice (Kokoro, Piper, Kitten): speed goes to sherpa-onnx (clamped 0.5 to 2) and
   playback runs at 1x. Pitch stays a playback control. Before, the finished audio was sped up by the player.
4. Faster first sound: the first piece an on-phone voice speaks is cut to about one sentence (90 characters), the rest stays in
   normal chunks; the next chunk is still made while the current one plays.
5. About changelog entry for V1.93.0; every version stamp set with scripts/bump-version.sh 1.93.0 (--check: all agree).

NOT CHANGED ON PURPOSE
- No Kotlin, Java, workflow or build-script change. HorizonVoicePlugin.kt already took speed, packs and downloads.
- The sherpa-onnx runtime stays pinned to v1.12.14 (the upstream main branch is 2.0.x and removed the espeak phonemizer these packs use).
  Newer voice models (Pocket TTS, Supertonic 3, Kitten v0.8) need that newer runtime and are a separate migration.

CHECKED AGAINST UPSTREAM (k2-fsa/sherpa-onnx, read from their repo in this session)
- Archive names kokoro-int8-multi-lang-v1_0, kokoro-multi-lang-v1_0 and kokoro-int8-multi-lang-v1_1 are produced by their export-kokoro workflow
  and uploaded to the tts-models release.
- Kokoro speaker order af 0-10, am 11-19, bf 20-23, bm 24-27 matches their kokoro-multi-lang-v1_0 page.
- The v1.12.14 Kotlin API has OfflineTtsKokoroModelConfig and generate(text, sid, speed), which the plugin uses.
- Not checked: the exact archive size on the release page (the card says about 130 MB), and whether the posted int8 archive already includes upstream
  change #4087 (int8 Kokoro export keeps the STFT convolutions in float32). If int8 Kokoro ever sounds buzzy, delete the pack and download it again later.

TESTED: node --check on every JS file; node unit tests 111/111 (6 new: HD download and select, hd.use, 28-voice list and speaker ids,
speed goes to the model with 1x playback and pitch kept, speed clamp, short first piece); headless Chromium at 412x915 with a stubbed
HorizonVoice plugin: card text per state, download progress 10/40/80 %, engine switches to Kokoro, status line, voice list starts with
Heart, Test calls load -> synth(sid 3, speed 1) -> play(rate 1, pitch 1), no page errors, screenshot checked.
NOT TESTED: Kotlin and Java compile (nothing changed there), APK build, the real download on a phone, how the real Kokoro sounds and how fast
it speaks on the Honor X5b. Rebuild through the GitHub workflow, then: Settings > Voice > Get HD voice (Wi-Fi), Test, read a long reply.
If the first sentence takes too long on the phone, pick a Piper voice (small) from the Voice library for speed.
