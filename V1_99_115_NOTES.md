# V1.99.115 - Groq (Free plan) back, Vault "Detect keys" and duplicate warnings

Built on horizon-V1_99_114.zip. The file access work from V1.99.114 is untouched.

GROQ (Free plan) RESTORED
- index.html: Groq provider (card, icon, OpenAI-style chat at api.groq.com, model list from the key's own /models, gsk_ key check, 429 retry). Default model openai/gpt-oss-120b.
- Startup no longer wipes Groq keys. Keys the V1.99.112 start already wiped are gone from the device: paste them again (or use Vault Detect, see below).
- horizon_net.js and HorizonAIPlugin.kt: api.groq.com added (OpenAI paths only). NEEDS AN APK REBUILD.
- horizon_model_policy.js: chat models only (no Whisper, TTS, guard, compound). Billing note: limits are per Groq account, so extra keys from the same account add no capacity; billed only if the organisation is upgraded to the Developer plan.
- horizon_key_import.js: gsk_ keys are claimed by Groq again.
- NOT restored: Groq in the page-ask AI, voice transcription, usage colours and the group list (V1.99.112 also removed it there).

VAULT: Detect keys (www/horizon_vault.js)
- New "Detect keys" button next to Lock now / Change passphrase.
- Finds the same key stored twice, whatever the titles, and lists the titles so you can remove the extra copy. Nothing is deleted for you.
- Finds Vault AI keys that are not in their provider card yet and lists each one with where it will land (backup slot, or main key if that provider has no main key yet).
- One tap moves them through the same verified path as Paste & extract: checked with the provider first, only keys that pass are saved. Then a result list (DONE / FAILED per key, and which slot it landed in) plus a notice. The Vault copies stay.
- Saving a Vault key that already exists under another title now warns you at once, and duplicate items show a warning line in the list.
- Scraping keys are not part of Detect yet.
