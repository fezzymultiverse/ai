Implemented

Shared AI instructionsOne native-first contract in horizon_toolpolicy.js, injected into full and lite prompts. Compact schemas remain intact instead of cutting module descriptions midway. Gateway model changes rebuild the appropriate prompt.
Native music and lyricsNewPipe-first yt.search / yt.play / yt.download; no model-written scraping for these tasks. Native lyrics.show uses the existing widget; highlighting depends on timed lyrics being available. Playing does not imply downloading.
PlaylistsNew yt.queue appends remote tracks through the existing player without interrupting current playback. Local tracks use music.queue. Playlist requests do not automatically become Termux downloads.
Termux opt-inRemoved automatic YouTube-to-Termux search/download fallbacks and obsolete helpers. yt-dlp is instructed only for explicit Termux/yt-dlp requests or native-unsupported formats such as 4K. Native failure alone does not authorize the switch.
Manual RUN workflowBash blocks in main chat and terminal chat have a manual RUN button. Legacy terminal run fences also become manual cards, not automatic commands. Results appear only after execution. Main-chat results are session-only and scoped to the originating chat; the next AI request receives the actual result as untrusted reference data. Terminal-card results join its conversation.
Rootless phone shellQuoted paths/URLs, pkg rather than sudo, noninteractive commands, yt-dlp -x --audio-format mp3, Git operations and health commands free -h / top -b -n 1. Unknown jobs are not blindly repeated.
Alarms and calendarWorking alarm.set / calendar.add aliases reuse existing calendar storage and native scheduling. Validation rejects invalid dates, missing times for reminders/alarms, past times and malformed labels. Native feedback precedes the AI confirmation; retries reuse the same item/id. Failures, inexact timing and notification-only fallback are reported honestly, including upcoming prompt state. Legacy dash.note remains supported.
Web, images and filesGeneral research/scraping remains available through configured Web tools for genuine web tasks. A conservative runtime guard rejects Web calls on explicit native-action requests. Native image/file tools stay available according to their own permission switches. No DRM/access-control bypass added.
CompatibilityExisting source layout, native plugin interfaces, media backend, historical release notes and prior screenshot preview remain. About version and changed-asset cache tags advance to V1.99.47. Removed the terminal auto-run toggle because this release requires manual RUN.
