# V1.99.117 - App icon fix

Built on horizon-V1_99_116. Web files untouched except version strings. Needs an APK rebuild (the icon is a native resource).

CAUSE
- The build step "Apply icons and splash" ran scripts/apply-android.sh, but that file (rebuilt in V1.99.114) only installed native plugins and said "No theme/icon/splash assets are changed". No icon source existed in the repo, so every APK shipped Capacitor's default icon.
- Android cannot use an SVG as a launcher icon. It needs PNGs per density plus an adaptive-icon XML.

FIX
- assets/icon.png (finished black tile) and assets/icon-foreground.png (transparent chip artwork) are your own icon files, used as they are. assets/icon.svg is only a fallback if icon.png is deleted.
- scripts/apply-icons.sh (pure Bash, uses rsvg-convert): proves the source renders first (refuses with a clear error otherwise), then writes ic_launcher, ic_launcher_round, ic_launcher_foreground for all 5 densities, the adaptive-icon XML, the icon background colour, and every splash.png Capacitor created (same pixel sizes). Also writes www/icon.png, which index.html already linked but did not exist.
- scripts/apply-android.sh now runs apply-icons.sh before the native install (HZ_SKIP_ICONS=1 skips). All existing checks kept.
- Workflow installs librsvg2-bin if the runner lacks it.

RUN IT BY HAND (Termux, no CI)
  pkg install librsvg
  npx cap add android            # only if android/ does not exist yet
  bash scripts/apply-icons.sh android
  npx cap sync android
Horizon's own terminal can run the same commands through the Termux bridge.

ICON RULE
- Square 1024 PNGs, artwork inside the middle 60%. Android crops adaptive icons to a circle/squircle. To change the icon, replace the two PNGs in assets/ and rebuild.

TESTS
- tests/icons-v117.test.cjs. Generator verified against a real `npx cap add android` project: 15 launcher PNGs, 11 splash images, idempotent, bad/blank SVG refused with nothing changed. NOT installed on a phone.
